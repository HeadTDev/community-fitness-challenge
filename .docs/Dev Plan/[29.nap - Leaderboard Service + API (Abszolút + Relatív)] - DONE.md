# 29.nap - Leaderboard Service + API (Abszolút + Relatív) 🚀

## 🎯 Napi Fókusz
Ez a nap a(z) Leaderboard Service + API (Abszolút + Relatív) megvalósításáról és a rendszer stabilitásának növeléséről szól. A cél egy jól tesztelt, fenntartható kódalap létrehozása.

## 🛠️ Technikai Stack & Konfiguráció
- **Runtime:** Go 1.26+, Docker Desktop
- **Infrastructure:** LocalStack (S3, SQS, SES, Secrets Manager)
- **Database:** PostgreSQL 18, Redis 8
- **Tools:** VS Code, Postman, `awslocal`

## 📝 Részletes Feladatlista
- [ ] GET /v1/challenges/:id/leaderboard?type=absolute 🔧 (Senior tipp: Mindig dokumentáld az API változásokat és frissítsd a Postman kollekciót.)
- [ ] GET /v1/challenges/:id/leaderboard/relative 🔧 (Senior tipp: Mindig dokumentáld az API változásokat és frissítsd a Postman kollekciót.)

## 💡 Senior DevOps Best Practice
Aszinkron feldolgozás: Az SQS használatával a hosszan tartó feladatokat (pl. email küldés, képfeldolgozás) leválasztjuk az API-ról, így a rendszer válaszkészebb marad.
