# 07.nap - AWS SDK Alap + S3 Kliens 🚀

## 🎯 Napi Fókusz
Ez a nap a(z) AWS SDK Alap + S3 Kliens megvalósításáról és a rendszer stabilitásának növeléséről szól. A cél egy jól tesztelt, fenntartható kódalap létrehozása.

## 🛠️ Technikai Stack & Konfiguráció
- **Runtime:** Go 1.26+, Docker Desktop
- **Infrastructure:** LocalStack (S3, SQS, SES, Secrets Manager)
- **Database:** PostgreSQL 18, Redis 8
- **Tools:** VS Code, Postman, `awslocal`
