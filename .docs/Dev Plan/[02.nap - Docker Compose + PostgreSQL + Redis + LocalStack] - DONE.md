# 02.nap - Docker Compose + PostgreSQL + Redis + LocalStack 🚀

## 🎯 Napi Fókusz
Ez a nap a(z) Docker Compose + PostgreSQL + Redis + LocalStack megvalósításáról és a rendszer stabilitásának növeléséről szól. A cél egy jól tesztelt, fenntartható kódalap létrehozása.

## 🛠️ Technikai Stack & Konfiguráció
- **Runtime:** Go 1.26+, Docker Desktop
- **Infrastructure:** LocalStack (S3, SQS, SES, Secrets Manager)
- **Database:** PostgreSQL 18, Redis 8
- **Tools:** VS Code, Postman, `awslocal`

## 💡 Senior DevOps Best Practice
Infrastruktúra kódként (IaC): Minden környezeti beállítást rögzíts docker-compose és init scriptekben. Ez garantálja a reprodukálhatóságot minden fejlesztőnél.

## ✅ Verifikáció & Tesztelés

# Futtasd az alábbi ellenőrzéseket:

`docker compose up -d → újra fut (PERSISTENCE=1, adatok maradnak!)`
