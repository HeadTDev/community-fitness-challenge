# 18.nap - Challenge Join/Leave + Redis Counter 🚀

## 🎯 Napi Fókusz
Ez a nap a(z) Challenge Join/Leave + Redis Counter megvalósításáról és a rendszer stabilitásának növeléséről szól. A cél egy jól tesztelt, fenntartható kódalap létrehozása.

## 🛠️ Technikai Stack & Konfiguráció
- **Runtime:** Go 1.26+, Docker Desktop
- **Infrastructure:** LocalStack (S3, SQS, SES, Secrets Manager)
- **Database:** PostgreSQL 18, Redis 8
- **Tools:** VS Code, Postman, `awslocal`

## 📝 Részletes Feladatlista
- [ ] POST /v1/challenges/:id/join 🔧 (Senior tipp: Mindig dokumentáld az API változásokat és frissítsd a Postman kollekciót.)
- [ ] POST /v1/challenges/:id/leave 🔧 (Senior tipp: Mindig dokumentáld az API változásokat és frissítsd a Postman kollekciót.)
- [ ] Redis INCR/DECR atomi számláló 🔧 (Senior tipp: Használj prefixeket a kulcsoknál (pl. app:user:123) az ütközések elkerülésére.)

## 💡 Senior DevOps Best Practice
Skálázhatóság: A Repository pattern lehetővé teszi, hogy később könnyen válts adatbázist vagy cache-elést anélkül, hogy az üzleti logikához hozzá kellene nyúlnod.
