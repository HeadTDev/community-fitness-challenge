# 10.nap - Auth Middleware + Auth Handler 🚀

## 🎯 Napi Fókusz
Ez a nap a(z) Auth Middleware + Auth Handler megvalósításáról és a rendszer stabilitásának növeléséről szól. A cél egy jól tesztelt, fenntartható kódalap létrehozása.

## 🛠️ Technikai Stack & Konfiguráció
- **Runtime:** Go 1.26+, Docker Desktop
- **Infrastructure:** LocalStack (S3, SQS, SES, Secrets Manager)
- **Database:** PostgreSQL 18, Redis 8
- **Tools:** VS Code, Postman, `awslocal`

## 💡 Senior DevOps Best Practice
Biztonság az alapoktól: A Secrets Manager használata és a JWT validáció kritikus. Soha ne bízz a kliens oldali validációban, a szervernek minden kérést hitelesítenie kell.

## ✅ Verifikáció & Tesztelés
```bash
# Futtasd az alábbi ellenőrzéseket:
`curl POST /auth/register-dev → JWT token visszajön`
`curl GET /v1/users/me -H "Authorization: Bearer <token>" → 200`
`curl GET /v1/users/me (token nélkül) → 401`
`curl GET /v1/aws-status → {"s3":"ok","sqs":"ok"}`
```
